# 简记账 - 功能规格说明

本目录包含所有功能的规格文档，采用规格驱动开发（Spec-Driven Development）方法。

## 目录结构

每个功能规格包含以下文件：
- `requirements.md` - 需求文档（用户故事和验收标准）
- `design.md` - 设计文档（技术方案和实现细节）
- `tasks.md` - 任务列表（实现步骤）

使用以下命令创建新功能规格：
