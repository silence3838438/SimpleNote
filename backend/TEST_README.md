## 故障排查

### 测试失败常见原因

1. **登录失败**
   - 检查测试用户是否创建：`node create-test-user.js`
   - 检查数据库连接是否正常

2. **OCR识别失败**
   - 检查测试图片是否存在：`ls test-data/ocr-samples/`
   - 检查百度OCR配置是否正确

3. **AI增强失败**
   - 检查 Cloudbase 环境变量是否配置
   - 检查 CLOUDBASE_APIKEY 是否有效
   - 查看后端日志：`tail -f /var/log/simplenote-api.log`

4. **404错误**
   - 检查路由文件是否上传：`ls routes/ai-enhance.js`
   - 检查服务是否重启：`ps aux | grep "node server.js"`
   - 重启服务：`/www/backend/restart-backend.sh`

## 注意事项

⚠️ **测试环境**：
- 测试脚本使用 `http://localhost:3000` 作为API地址
- 仅在服务器本地运行测试

⚠️ **测试数据**：
- 测试会创建真实的用户账号和账单数据
- 建议定期清理测试数据

⚠️ **性能影响**：
- AI增强调用会消耗腾讯云资源
- 建议在非高峰期运行测试
