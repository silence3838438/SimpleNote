```bash

# 或者从本地执行
sshpass -p '520silenceW' ssh root@8.218.209.109 "cd /www/backend && node migrate-db.js"

# 迁移脚本功能:
# ✓ 自动检查是否需要执行迁移
# ✓ 跳过已执行的迁移
# ✓ 显示详细的执行结果
# ✓ 不会重复执行相同的迁移
```

**添加新的数据库迁移:**

编辑 `backend/migrate-db.js`,在 `migrations` 数组中添加新的迁移任务:

```javascript
{
  name: '迁移任务描述',
  sql: 'ALTER TABLE xxx ...',
  checkSql: "SELECT ... FROM INFORMATION_SCHEMA.COLUMNS WHERE ...",
  shouldRun: (result) => {
    // 返回 true 表示需要执行,false 表示跳过
    return result.length > 0 && result[0].DATA_TYPE !== 'bigint';
  }
}
```

   ```bash
   # 🔑 API Key: 已配置
   ```

#### API Key 类型说明

**重要区别：**

| 类型 | 用途 | 权限 | client_type | is_system_admin |
|------|------|------|-------------|-----------------|
| 客户端 Publishable Key | 浏览器/小程序 | 匿名访问 | `client_user` | `false` |
| 服务端 API Key | Node.js 后端 | 完整权限 | `client_server` | `true` |

**后端必须使用服务端 API Key**，不要使用客户端 Publishable Key！

#### 多个 API Key 管理

- 可以创建多个服务端 API Key（如：微信小程序用一个，后端服务用一个）
- 每个 Key 独立工作，互不影响
- 环境变量 `CLOUDBASE_APIKEY` 决定后端使用哪个 Key
- 建议命名规范：
  - "后端AI服务" - Node.js 后端使用
  - "小票识别AI" - 微信小程序使用

#### 故障排查

**问题：AI 响应为空或返回错误**

```bash

grep CLOUDBASE_APIKEY /www/backend/.env

# 2. 查看 AI 调用日志

# "is_system_admin": true
```

**问题：提示"missing secretId or secretKey"**

原因：没有配置 `CLOUDBASE_APIKEY` 环境变量

解决：按照上面的配置步骤添加 API Key

### 常见问题及解决方案

#### 1. 502 Bad Gateway 错误

**排查步骤**：
```bash
# 1. 检查后端服务是否运行
ps aux | grep 'node server.js'

# 2. 查看后端错误日志

# 3. 查看 Nginx 错误日志
tail -30 /var/log/nginx/error.log
```

**解决方案**：
```bash
# 重启后端服务
cd /www/backend
pkill -f "node server.js"
nohup node server.js > /var/log/simplenote-api.log 2>&1 &

# 等待3秒后检查
sleep 3 && tail -20 /var/log/simplenote-api.log
```

**问题描述**：上传头像后显示 404 或 500 错误

**原因**：

2. 静态文件服务未配置

**解决方案**：

已修复内容：
- `backend/routes/upload.js` - 返回完整URL（包含协议和域名）

重启服务：
```bash
cd /www/backend
pkill -f "node server.js"
nohup node server.js > /var/log/simplenote-api.log 2>&1 &
```

验证：
```bash

# 测试文件访问

```

#### 4. 数据库表缺少字段

**错误信息**：`Unknown column 'xxx' in 'field list'`

**解决方案**：
```bash
# 使用 Node.js 脚本添加字段
cat > /tmp/add_column.js << 'EOF'
const mysql = require('mysql2/promise');

async function addColumn() {
  const connection = await mysql.createConnection({
    host: '127.0.0.1',
    port: 3306,
    user: 'root',
    password: 'Qiannaqule2024!',
    database: 'simplenote'
  });
  
  try {
    // 修改这里的 SQL 语句
    await connection.execute("ALTER TABLE users ADD COLUMN avatar_url VARCHAR(500) DEFAULT '' AFTER nickname");
    console.log('✅ 字段添加成功');
  } catch (error) {
    console.error('❌ 错误:', error.message);
  } finally {
    await connection.end();
  }
}

addColumn();
EOF

cd /www/backend && node /tmp/add_column.js
rm /tmp/add_column.js
```
