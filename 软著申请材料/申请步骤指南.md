## 🔍 申请后跟踪

### 查询申请进度
1. 登录中国版权保护中心官网
2. 进入"用户中心"
3. 点击"我的申请"
4. 查看申请状态：
   - **待审核**：材料已提交，等待审核
   - **审核中**：正在审核材料
   - **补正**：需要补充或修改材料
   - **审核通过**：申请成功，等待制证
   - **已发证**：证书已制作完成

### 申请状态说明

#### 1. 待审核（1-3天）
- 系统自动检查材料完整性
- 无需操作，耐心等待

#### 2. 审核中（1-2个月）
- 审核员人工审核材料
- 检查源代码、说明书、身份证明
- 无需操作，耐心等待

#### 3. 补正（如果需要）
- 收到补正通知（短信/邮件）
- 登录系统查看补正要求
- 按要求修改材料后重新提交
- 补正期限：30天

**常见补正原因**：
- 源代码格式不符合要求
- 软件说明书字数不够
- 身份证明不清晰
- 申请信息填写错误

#### 4. 审核通过（1-2周）
- 收到审核通过通知
- 等待制作证书
- 无需操作

#### 5. 已发证（1-2周）
- 证书制作完成
- 选择领取方式：
  - **自取**：到版权中心现场领取（免费）
  - **邮寄**：快递到指定地址（需支付邮费）

## 📞 常见问题处理

### Q1：上传文件失败怎么办？
**解决方法**：
1. 检查文件格式是否正确
2. 检查文件大小是否超限
3. 尝试更换浏览器（推荐Chrome）
4. 清除浏览器缓存后重试
5. 联系客服：010-68003887

### Q2：忘记登录密码怎么办？
**解决方法**：
1. 点击登录页面的"忘记密码"
2. 输入注册手机号
3. 获取验证码
4. 设置新密码

### Q3：收到补正通知怎么办？
**解决方法**：
1. 登录系统查看补正要求
2. 根据要求修改材料
3. 重新上传修改后的文件
4. 提交补正申请
5. 等待再次审核

### Q4：审核时间太长怎么办？
**解决方法**：
1. 官方审核周期：2-3个月
2. 可在线查询进度
3. 如超过3个月未审核，可致电咨询
4. 如需加急，可联系第三方代理机构

### Q5：证书丢失怎么办？
**解决方法**：
1. 登录系统申请补发
2. 提供证书编号
3. 支付补发费用（50元）
4. 等待制作新证书
