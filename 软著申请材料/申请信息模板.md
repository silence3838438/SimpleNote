## 三、软件技术特点

### 1. 开发语言
- 前端：JavaScript (Vue.js 3)
- 后端：JavaScript (Node.js)
- 数据库：MySQL、MongoDB

### 2. 开发平台

- 后端框架：Express.js
- 开发工具：HBuilderX、Visual Studio Code

### 3. 运行平台/操作系统
- 微信小程序平台
- iOS 10.0及以上
- Android 5.0及以上
- Web浏览器（Chrome、Safari、Firefox等）

### 4. 硬件环境
- 最低配置：1GB RAM，100MB存储空间
- 推荐配置：2GB RAM，500MB存储空间
- 网络要求：支持3G/4G/5G/WiFi网络连接

### 5. 软件用途和技术特点
本软件是一款智能记账应用，主要用于个人和家庭的日常收支管理。软件采用跨平台技术架构，支持微信小程序、iOS和Android多端运行。

**核心技术特点**：
1. **AI智能识别**：集成百度OCR和语音识别API，支持拍照识别小票和语音输入记账
2. **跨平台架构**：基于uni-app框架，一套代码多端运行
3. **云端同步**：小程序端使用微信云开发，APP端使用独立后端API
4. **数据可视化**：提供多维度数据统计和图表分析
5. **游戏化设计**：积分系统、等级体系、红包雨活动提升用户粘性
6. **隐私保护**：支持金额隐藏、数据加密传输
7. **国际化支持**：支持中英文双语切换

### 4. 常见问题
**Q1：软件还在开发中可以申请吗？**
A：可以，只要有可运行的版本即可申请。

**Q2：开源软件可以申请软著吗？**
A：可以，开源不影响著作权归属。

**Q3：多人合作开发如何申请？**
A：可以申请共同著作权，需要所有著作权人签字。

**Q4：软著证书有效期多久？**
A：软件著作权保护期为50年，自软件首次发表之年起算。

**Q5：申请被驳回怎么办？**
A：根据驳回理由修改材料后重新提交，不需要重新缴费。
