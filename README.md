# 钱哪去了 - 智能记账小程序

一款简单易用的微信小程序，帮助你轻松记账，了解消费去向。

## ✨ 核心功能

### 📸 多种记账方式
- **拍照记账**：拍摄小票，AI自动识别金额和类别
- **语音记账**：说一句话，自动记录账单
- **手动记账**：传统输入方式，灵活记录

### 📊 数据分析
- 月度消费统计
- 分类支出分析
- 收支趋势图表
- Excel数据导出

### 🎮 游戏化体验
- 春节红包雨活动
- 积分系统
- 会员等级升级
- 成就勋章

### ⏰ 智能提醒
- 每日记账提醒
- 自定义提醒时间
- 微信订阅消息推送

## 🛠 技术栈

- **前端框架**：uni-app (Vue 3)
- **云服务**：微信云开发
- **AI能力**：
  - 百度OCR文字识别
  - 百度语音识别
  - AI智能分类

## 🚀 快速开始

### 环境要求
- Node.js 14+
- 微信开发者工具
- 微信云开发环境

### 安装步骤

1. 克隆项目
```bash
git clone https://github.com/silence3838438/SimpleNote.git
cd SimpleNote
```

2. 安装依赖
```bash
npm install
```

3. 配置云环境
- 在微信开发者工具中打开项目
- 开通云开发服务
- 修改云环境ID（在云函数中）

4. 部署云函数
- 右键各个云函数目录
- 选择"上传并部署：云端安装依赖"

5. 配置API密钥
- 百度AI开放平台申请OCR和语音识别API
- 在对应云函数的`config.json`中配置密钥

### 运行项目
在微信开发者工具中点击"编译"即可预览

## 📝 云函数说明

### billManager
账单管理云函数，处理账单的增删改查操作

### ocrRecognize
OCR识别云函数，识别小票图片中的金额和商品信息

### voiceRecognize
语音识别云函数，将语音转换为文字并提取记账信息

### sendReminder
定时提醒云函数，每5分钟检查并推送记账提醒
- 定时触发器：`0 */5 * * * *`
- 使用北京时间（UTC+8）

### exportExcel
数据导出云函数，生成Excel格式的账单报表

## 🔐 隐私说明

- 所有数据存储在微信云数据库
- 数据加密传输
- 仅用户本人可访问
- 支持数据导出和删除
