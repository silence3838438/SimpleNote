二、软件概述

-------------------------------------------------------------------------------

2.1 软件简介

钱哪去了是一款智能记账应用，支持微信小程序、iOS和Android平台。通过AI技术（OCR识别、语音识别）让记账变得简单、智能、有趣。


2.2 主要功能

1. 多种记账方式
   - 拍照记账：拍摄小票，AI自动识别金额、商家和类别
   - 语音记账：语音输入，自动记录账单
   - 手动记账：传统输入方式

2. 数据分析与统计
   - 月度统计：收入、支出、结余
   - 分类分析：按类别统计支出占比
   - 趋势分析：查看消费趋势

3. 预算管理
   - 设置月度预算
   - 实时监控使用率
   - 超支预警

4. 数据导出
   - 支持导出Excel格式账单

5. 管理后台
   - 用户管理：查看用户列表、统计数据
   - 账单管理：查看所有账单记录
   - 版本管理：发布新版本、管理APK文件
   - 二维码管理：上传和管理安卓下载二维码
   - 反馈管理：查看用户反馈

6. 国际化支持
   - 支持中文、英文双语切换
   - 自动检测系统语言

五、使用说明

-------------------------------------------------------------------------------

5.1 用户注册与登录


5.1.1 注册账号

1. 打开应用，点击"注册"按钮
2. 输入手机号
3. 获取并输入验证码
4. 设置密码
5. 阅读并同意用户协议和隐私政策
6. 点击"注册"完成

[注册界面](注册界面截图)


5.1.2 登录账号

1. 打开应用
2. 输入手机号和密码
3. 点击"登录"
4. 或使用微信快捷登录

[登录界面](登录界面截图)


-------------------------------------------------------------------------------

5.2 记账功能


5.2.1 拍照记账

1. 点击首页"拍照记账"按钮
2. 拍摄或选择小票照片
3. 系统自动识别金额和商家信息
4. 确认信息后保存

[拍照记账界面](拍照记账截图)


5.2.2 语音记账

1. 点击首页"语音记账"按钮
2. 按住录音按钮说话
3. 例如："今天午饭花了25块"
4. 系统自动识别并填充信息
5. 确认后保存

[语音记账界面](语音记账截图)


5.2.3 手动记账

1. 点击首页"手动记账"按钮
2. 选择收入或支出
3. 输入金额
4. 选择分类
5. 填写备注（可选）
6. 点击"保存"

[手动记账界面](手动记账截图)


-------------------------------------------------------------------------------

5.3 账单管理


5.3.1 查看账单列表

1. 点击底部导航"账单"
2. 查看所有账单记录
3. 可按时间、分类筛选

[账单列表界面](账单列表截图)


5.3.2 编辑账单

1. 在账单列表中点击某条账单
2. 进入账单详情页
3. 点击"编辑"按钮
4. 修改信息后保存


5.3.3 删除账单

1. 在账单详情页点击"删除"
2. 确认删除操作


-------------------------------------------------------------------------------

5.4 统计分析


5.4.1 查看统计数据

1. 点击底部导航"统计"
2. 查看月度收支统计
3. 查看分类占比图表
4. 查看趋势分析

[统计界面](统计界面截图)


5.4.2 切换时间范围

1. 在统计页面顶部选择时间范围
2. 可选择本月、本年或自定义时间


-------------------------------------------------------------------------------

5.5 预算管理


5.5.1 设置预算

1. 进入"我的" → "预算管理"
2. 输入月度预算金额
3. 点击"保存"


5.5.2 查看预算使用情况

1. 在首页查看预算使用进度
2. 超支时会显示预警提示


-------------------------------------------------------------------------------

5.6 数据导出


5.6.1 导出账单

1. 进入"账单"页面
2. 点击"导出"按钮
3. 选择导出时间范围
4. 生成Excel文件
5. 保存到本地


-------------------------------------------------------------------------------

5.7 设置功能


5.7.1 语言设置

1. 进入"我的" → "系统设置" → "语言设置"
2. 选择"简体中文"或"English"
3. 系统自动切换语言

[语言设置界面](语言设置截图)


5.7.2 记账提醒

1. 进入"我的" → "记账提醒"
2. 开启提醒开关
3. 设置提醒时间
4. 保存设置


5.7.3 意见反馈

1. 进入"我的" → "意见反馈"
2. 输入反馈内容
3. 提交反馈

八、常见问题

-------------------------------------------------------------------------------

8.1 无法登录

- 检查网络连接
- 确认手机号和密码正确
- 尝试重置密码


8.2 拍照识别失败

- 确保小票清晰可见
- 光线充足
- 重新拍摄


8.3 语音识别不准确

- 在安静环境下录音
- 说话清晰
- 重新录音


8.4 数据同步问题

- 检查网络连接
- 重新登录账号
- 联系客服
